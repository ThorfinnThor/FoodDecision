# Image Provenance

- `food-decision-hero.png` is a project-created image generated specifically
  for Compare Your Food. It is not sourced from a stock library or a
  third-party product catalog.
- Imported product images are not stored in this directory. The application
  displays them only from approved HTTPS Open Food Facts hosts, labels them
  `CC BY-SA`, and links each visible image to its source product page.
- Do not add third-party images without recording the source URL, creator,
  license, and required attribution here.

## Category photos

The files in `categories/` are web-sized copies downloaded through Wikimedia
Commons. The application links every visible category hero to its Commons file
page, and `/de/image-credits` plus `/en-us/image-credits` provide a complete
in-product attribution list. The files are not retouched; the UI uses CSS
`object-fit` and `object-position` for responsive framing.
