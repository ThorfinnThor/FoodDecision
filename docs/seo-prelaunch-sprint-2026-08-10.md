# SEO Prelaunch Sprint

## Scope

This sprint prepares useful ranking pages before the custom domain is ready.
It does not publish unvalidated search pages.

## Implemented

- Added bilingual ranking directories at `/de/best` and `/en-us/best`.
- Linked the directory from desktop navigation, mobile navigation, and the
  footer.
- Registered three curated German and three curated US launch candidates with
  market specific titles, descriptions, headings, summaries, canonicals, and
  internal links.
- Kept every candidate on `noindex,follow` and outside the sitemap.
- Extended the build report to distinguish technical quality blockers from
  human publication blockers.

## Publication Requirements

Each candidate needs all of the following before indexation:

1. `compareyourfood.com` is connected and set as the production site URL.
2. The intended query has documented market specific demand and a reviewed
   search results page.
3. The keyword changes from `candidate` to `approved`.
4. The page changes from `review` to `published` and `indexable` becomes true.
5. The SEO validation report shows no quality blockers.
6. Canonical, language alternatives, structured data, desktop layout, and
   mobile layout are reviewed on production.

Affiliate availability never affects ranking order or search publication.
